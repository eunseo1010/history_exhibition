# 3D 맵 뷰어

Blender에서 내보낸 `Map.glb`를 Three.js로 전체 화면에 표시합니다. 모델의 메시, 재질, 텍스처 또는 비율은 변경하지 않으며 화면에 맞게 위치만 중앙 정렬합니다.

`public/models`의 `NPC_A.glb`, `NPC_B.glb`, `NPC_C.glb`, `NPC_J.glb`, `NPC_U.glb`도 별도로 불러와 맵에 배치합니다. 각 NPC는 `Wood` 높이에 맞춰 균일하게 크기를 조정하고, 배치 위치의 맵 지면을 기준으로 발 높이를 맞춥니다. 원본 맵 GLB와 NPC 모델의 재질 및 텍스처 파일은 수정하지 않습니다.

뷰어는 태양을 포함한 낮 하늘 그라데이션 배경과 방향성 태양광, 부드러운 반구광, PCF 그림자, SSAO 및 ACES 톤 매핑을 사용해 조명과 깊이감을 표현합니다. 중앙 정자와 벽 쪽 건물에는 은은한 실내 조명과 창가 빛 번짐 효과를 더합니다. 성능을 위해 밀집 잔디 잎은 그림자를 만들지 않지만 다른 오브젝트의 그림자는 받습니다.

## 실행

1. VS Code에서 이 폴더를 엽니다.
2. Node.js 20.19 이상(또는 22.12 이상)을 설치합니다.
3. 터미널에서 다음 명령을 실행합니다.

```bash
npm install
npm run dev
```

터미널에 표시되는 로컬 주소를 브라우저에서 엽니다. 모델을 드래그하여 회전하고 스크롤하여 확대/축소할 수 있습니다.
